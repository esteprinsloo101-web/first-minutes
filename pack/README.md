# First Minutes — First Aid Wait Pack

**Brand:** First Minutes (faceless)  
**Offer:** Free demo web app + paid printable wait pack (**R129**)

## What’s in this pack

| File | Purpose |
|------|---------|
| `DISCLAIMER.md` | Hard safety fence — keep with every distribution |
| `README.md` | This file |
| `cards/` | Printable HTML wait cards (print → PDF / paper) |

## How to use

1. Read `DISCLAIMER.md`.
2. Open any card in `cards/` in a browser → Print (A5 or A4).
3. Keep copies in car / kitchen / office.
4. In emergency: **call 112** first — cards are for the wait, not instead of EMS.

## Companion free demo

Static web app (situations + DEMO facilities board + who to call).  
Facility rows are always `demo: true` until verified.

## Safety reminders

- Not a doctor / not EMS / not hospital finder of record
- DEMO facilities + example medical aids only
- Adults 18+
