💫 Fainting / near-faint

1. Near-faint: lie down or sit head between knees.
2. If fainted: check response + breathing. Call 112 if not waking / abnormal breathing.
3. Lie flat; raise legs if no injury suspected.
4. Loosen clothing at neck. No food/drink until fully alert.
5. Sit up slowly when recovered.
6. Call 112 if after chest pain, head injury, seizure, or it repeats.
